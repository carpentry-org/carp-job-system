carp-job-system

A POSIX-threads thread pool for Carp, and a set of parallel collection operators built on top of it.

(load "git@github.com:carpentry-org/carp-job-system@master")

The pool

  • JobSystem — pool lifecycle, job submission, and waiting
  • Future — a handle to a result that is not ready yet

Parallel operators

  • Rayon — fork-join over a range
  • Par — parallel map, filter, reduce, find and friends over arrays, in the shape rust's rayon uses. the SIMD paths come from carp-math.

The C side lives in jobs.h and is pulled in with relative-include, so it travels with the library.
